# WorkX 空间制 SaaS 产品设计

版本：0.3 · 2026-10-30 · 已有本地多空间原型，真实账号与后端待建设

WorkX 采用 personal／organization 两类 Tenant。每位用户有唯一个人空间，并可加入多个组织；空间是任务、项目、文件、伙伴、连接与用量的归属边界。全局 User 偏好与当前组织管理分开，完整规范见 [租户模型](../../docs/TENANCY-MODEL.md)。

## 入口与页面

| 入口 | 当前原型 |
| --- | --- |
| 侧栏账号菜单／当前空间栏 | 列出个人与已有组织、当前标记、创建组织；组织内提供邀请成员与组织管理。 |
| 个人设置 | `#settings/general`：语言与本地提醒；`profile`：显示名称与演示邮箱；`spaces`：本人空间列表。偏好不随空间切换改变。 |
| 组织管理 | `#team/general`：名称和空间标识；`members`：成员与邀请；`permissions`：角色矩阵；`data`：资源共享；`connections`：连接归属；`usage`：本地数量；`activity`：管理活动。 |
| 个人空间设置 | 基本归属、资源、连接及用量；不能邀请第二人、维护组织成员或使用组织共享连接。 |
| 工作台／项目 | 任务、分工、背景与成果确认继续放在日常工作中，不与组织管理平铺混排。 |

## 对象与实现边界

| 对象 | 产品规则 | 当前原型 |
| --- | --- | --- |
| Tenant | 个人本人独占，组织可多人；加入组织不迁移个人数据。 | 原 WorkX 组织保留旧记录；个人及新组织有独立本地 data 对象，支持切换／刷新。 |
| User | 全局身份与偏好。 | Alex 演示身份，显示名称与偏好全局保存；无真实登录。 |
| Membership | 每空间角色与状态；组织至少一个 owner。 | 成员仅在当前组织出现，owner 受保护；本地角色按钮检查不等于后端鉴权。 |
| Invitation | 邮箱、角色、邀请者、期限与一次性接受。 | 批量邮箱校验／去重、pending／accepted／cancelled／expired、7 天期限、演示接受；不发送邮件、不创建真实账号。 |
| Department | 可选成员属性，无首版权限继承。 | 不再在主导航提供部门树；兼容既有部门元数据及成员属性，保留旧编辑逻辑供兼容。 |
| ResourceGrant | owner、指定成员、项目成员、组织 active 成员范围；写操作另外授权。 | 数据页可维护 private／selected／project／space 元数据；个人固定 private。 |
| Connection／Vault | 当前租户内成员私有／组织服务归属，工具与渠道分离。 | 登记平台、认证方式、归属、伙伴关联和启停；仅元数据，无真实 Token、密钥或 Vault。 |

## 权限决定

空间角色管理组织操作，资源范围决定具体内容可见／使用权限，上游 scope 决定外部工具能力；三者必须分别通过。owner／admin 不自动获得成员私有内容；共享伙伴不共享创建者的凭证。部门、上下级关系和外部昵称都不能推导授权。

资源所有者与任务负责人分开。原型 resourceOwnerId 表示资源归属，既有任务 ownerId 仍表示分工负责人；调整分工不改变资源所有权。组织内共享不代表编辑、删除、导出或批准外部写操作。

个人连接与组织内成员私有连接有不同 tenant；同一用户的两个空间也不能互借。飞书／企微机器人渠道配置在生态接入管理，不能用机器人身份替代用户业务 API consent。

## 生命周期与本地保存

创建组织保留 personal，默认仅创建者一人，新组织不复制已有任务、文件、项目或连接；内置伙伴为固定示例，不是复制用户自定义伙伴。接受邀请只增加目标组织的一条成员关系；个人空间不增加成员、不迁移资源。

本地存储使用 `workx-spaces-v1`。旧 `workmates-prototype-v1` 作为只读迁移来源保留，旧业务记录只进入旧组织；后续新增和修改写新结构。语言仍用 `workx-locale`。普通任务／Code 草稿按空间仅保留内存，切回可继续，刷新清空；密钥不进入草稿缓存。

切换关闭敏感配置弹窗、清空临时参数、重置旧路由和资源选择；运行任务回调持有原空间数据，不更新新空间。当前不承诺多标签页并发编辑同步、真实跨账号协作或数据库／对象存储隔离。

## 原型验收

1. 从旧版进入，新建 personal 但旧任务／绑定仅在 WorkX 组织；切换回来仍可见旧记录。
2. 个人设置独立于组织管理；组织切换不改变语言和账号资料。
3. 创建组织后只有本人 owner，资源为空；个人连接不出现在新组织。
4. 邀请邮箱不合法、重复或已是成员时拒绝；演示接受只增加一次成员，撤销／过期后不可接受。
5. 数据页可维护本空间共享范围；只接受本空间的成员／项目，部门变化不扩大授权。
6. 连接登记区分成员私有／组织服务，无认证也能登记；OAuth／静态／换取／env-file 保持待真实授权。
7. 关闭／切换后 Secret 表单临时值清空；元数据不包含真实 Secret 或 .env 内容。
8. 运行中切换空间，回调只更新原空间；普通草稿切回可继续；刷新恢复当前空间和已保存数据。
9. 中英路由、用户内容转义、桌面与移动布局分别验证。
